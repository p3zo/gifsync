How to use it


    
  
  1. Drop in a GIF. Gifsync predicts the frames the beat should land
    on.
    2. 
  
  2. Drop in a song. Gifsync estimates the tempo and marks the first few
    beats.
    3. 
  
  3. Make adjustments. Drag the edges of the waveform in to use one part
    of the song. Move the marks, type the tempo, or tap it out. Set how often the GIF hits,
    and what happens between beats.
    4. 
  
  4. Save the video.
    5.
